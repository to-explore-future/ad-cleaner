# 广告拦截助手

> 像 F12 一样在网页上点选要拦的元素 —— 而且能**沿着 DOM 树往外扩一层**再拦。

浏览器扩展（Chrome / Edge，MV3）。做这个是因为 Adblock Plus / uBlock 的元素选择器有个硬伤：

**浏览器的命中测试永远返回最里层的元素。**

```html
<div class="ad-box">        ← 你真正想拦的
  <div class="ad-wrap">
    <div class="ad-inner">  ← 鼠标实际命中的
      <img src="ad.png">
```

拦住最里层只藏掉一张图，外层那个空白框还在。想往外走一层只能盲按快捷键，看不见结构，根本不知道自己选到了哪。

---

## 它怎么解决

打开扩展，右侧是面板，左侧就是网页本身：

```
① 点「＋ 选中要拦的东西」进入选择模式
② 鼠标在页面上滑动     → 右侧实时显示这块 DOM 的祖先链（F12 那种对应关系）
③ 点一下               → 锁定当前这层（鼠标再怎么动都不变）
④ 要往外扩一层         → 直接点右侧树里的上级
⑤ 点「拦截这个」        → 立刻生效
```

选中之后还会告诉你**这一刀会砍掉多少**：

```
这类卡片共有 12 个（页面上已用蓝色虚线全部标出）
范围  [同类 12]  [只这一个]
```

这一步是刻意做的 —— Adblock Plus 只告诉你"选中了"，不告诉你"会波及多少"。

## 主要能力

| 能力 | 说明 |
|---|---|
| **F12 式点选** | 悬停跟随、点击锁定、再点一下取消选中，回到悬停模式 |
| **DOM 树外扩** | 右侧祖先链，点哪层选哪层；树里悬停时页面对应高亮（双向联动） |
| **同类识别** | 用**单个 class** 识别"这一类元素"，页面上全部标出 |
| **条件规则** | 同类卡片太多时，只拦内部含「广告」/某个元素的那些；条件可嵌套，可严格限制层级 |
| **两种拦截方式** | 隐藏（`display:none`，保留布局）／删除（真从 DOM 移除） |
| **预览效果** | 先真的应用一次看结果，再点一下恢复 |
| **规则管理** | 每条规则可开关、编辑、删除，显示当前命中几个元素 |
| **本页 / 本网站** | 默认只列当前页面真正命中的规则；可切换看本站全部 |
| **规则备份** | 导出成 JSON / 从文件导入（按 domain + selector 合并，不覆盖已有） |
| **关于页** | 版本进度、后续计划、当前版本号 |

## 使用

### 拦一个广告

1. 点工具栏的「ADB」图标 → 右侧面板打开
2. 点「＋ 选中要拦的东西」
3. 在页面上点一下广告（点图片、标题、边角都行）
4. 看右侧：如果只圈中一小块，就点树里的**上一级**，直到整块广告被框住
5. 点「拦截这个」

### 只拦带「广告」的卡片（条件规则）

信息流里普通卡片和广告卡片 class 完全一样，按 class 拦会把整条流干掉。

1. 选中**整张卡片**（在右侧树里往上点到卡片那一层）
2. 在底部「锚」这一行填 `广告` —— 只要卡片内部任意层出现这两个字就拦
3. 页面上会立刻从「同类 6 个」收敛到「真正命中 2 个」，按钮变成「拦截这个（含文字）」
4. 点它

要更精确：

- 在树里**勾选**卡片内部的标签（比如广告角标）作为条件；
- 打开「严格限制层级关系」，给每个条件填「第 N 层」；
- 条件行还能再填文字，或继续勾它内部的标签做嵌套条件。

编辑已有规则时，锚点、勾选、文字和严格层级都会原样复现，改完点「保存修改」。

### 取消 / 修改

- 规则左边的 ✅ 取消勾选 → 刷新页面，被拦的东西就回来了
- ✎ 重新进入选择模式并定位到原目标
- 🗑 删掉这条规则

### 悬浮看影响范围

鼠标停在某条规则上，页面会把它影响的所有元素标出来。
**已经生效的规则**（元素已被隐藏）会临时显形（虚线框），移开就恢复。
这个行为可以在顶部「显示拦截效果」开关里关掉。

## 规则是什么

一条规则 = **域名 + 锚点选择器 + 条件（可选） + 方式**

```
www.example.com   ##   div.ad-slot                    ## 隐藏
www.bilibili.com  ##   div.feed-card 含「广告」         ## 隐藏
www.example.com   ##   div.ad-box（▸1 div.ad-wrap（▸1 div.ad-inner）） ## 隐藏
```

`含「广告」` 表示锚点子树任意层出现这段文字；`▸1` 表示"正好下一层"（严格层级模式）。

选择器由扩展自动生成，你不需要手写。生成规则：

1. **优先用类名**（`div.ad-slot`）—— 页面结构一改就失效的位置选择器（`:nth-of-type`）只作兜底
2. **唯一性实测**（`querySelectorAll(sel).length === 1`），不靠推断
3. 自动过滤掉构建工具生成的哈希类名（`css-1x2y3z` 这类）

## 隐私

**不联网、不上传、不统计。**

- 规则只存在你自己浏览器的 `chrome.storage.local` 里
- 扩展没有任何网络请求，也没有后端
- 权限只有三个：`storage`（存规则）、`scripting`（页面脚本缺失时补注入）、`sidePanel`（侧边栏），
  加上 `<all_urls>` 是为了在任何网站都能工作

### 自测

测试全部用 **无头 Chrome + CDP** 跑，不会弹窗口打扰你：

```bash
node scripts/server.cjs &          # 本地测试页（:8941）
npm run verify:real                # 生产路径端到端（103 项）
node scripts/verify.cjs            # 完整套件（25 项）
npm run probe:lock                 # 真 B 站页面：锁定后是否真的不动
npm run probe:reload               # 重载扩展后控制台是否刷错误
```

`scripts/fixture/index.html` 是测试页，里面有刻意构造的嵌套广告结构与同款元素。

### 目录

```
entrypoints/
  picker.content/     页面侧：选择模式 + 注入 CSS + 规则执行
  sidepanel/          侧边栏 UI（Vue 3）
  background.ts       只为打开侧边栏
utils/
  types.ts            规则与元素的数据结构
  selector.ts         选择器生成 / 唯一性校验 / 祖先链
  rules.ts            存储、导入导出、CSS 生成
  changelog.ts        版本进度与计划（直接显示在扩展的「关于」页）
scripts/              测试与探针
```
