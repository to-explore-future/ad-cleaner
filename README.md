# 广告拦截助手（ADB）

> 网页上的广告，点一下就没。

Chrome / Edge 扩展。像 F12 一样在网页上点选元素，**沿完整 DOM 树往外扩**，
按文字或层级加条件，只拦你指的那一块，不误伤整页内容。

- 官网（安装包下载 + 各浏览器安装方式）：**https://tianrunye.com/adcleaner**
- 最新版本：**v0.3.4**
- 下载：见 [Releases](../../releases) 或官网的「下载 ZIP」

---

## 它解决什么问题

浏览器自带的命中测试**永远返回最里层的元素**：

```html
<div class="ad-box">        ← 你真正想拦的
  <div class="ad-wrap">
    <div class="ad-inner">  ← 鼠标实际命中的
      <img src="ad.png">
```

拦住最里层只藏掉一张图，外层那个空白框还在。普通元素选择器让你盲按快捷键往上爬，
看不见结构，也不知道选到了哪一层。

广告拦截助手把**整条祖先链**摆在你面前，点哪层选哪层；还能看到"这一刀会砍掉多少"。

## 怎么用

### 1. 安装

商店上架前用 ZIP 安装（四步，一分钟）：

1. 从 [官网](https://tianrunye.com/adcleaner) 或 [Releases](../../releases) 下载 ZIP，解压到固定文件夹
   （解压后应能直接看到 `manifest.json`）
2. 浏览器地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选刚才那个文件夹 → 固定到工具栏

### 2. 拦一块广告

1. 点工具栏的 ADB 图标，右侧打开面板
2. 点「＋ 选中要拦的东西」
3. 鼠标在页面上移动，右侧实时显示这块 DOM 的祖先链
4. **点一下锁定**当前层；要往外扩一层，就在右侧树里点它的上级
5. 点「拦截这个」

### 3. 只拦同款里的某几个（加条件）

同一个列表里，广告卡片和正常卡片 class 完全一样。做法：

1. 在树里勾选外层卡片那一层
2. 找到那个能区分广告的子节点（比如角落里的 `「广告」` 角标），也勾上
3. 在下面的输入框里给它填文字约束（或先在内容里划选文字，点「选中的字」）
4. 点「组合成规则」

结果：**包含这段文字的那几个才拦**，正常内容一个不动。

### 4. 管理规则

- 规则列表顶部：`本页 N` / `本网站 N` —— 默认只看当前页面真正命中的
- 每条规则可以：开关、编辑、删除，右侧显示当前命中几个
- 鼠标悬浮在规则上，页面会标出它影响的所有元素
- 规则可导出 JSON、从文件导入（按规则身份合并，不会重复）

### 5. 快捷键

- 鼠标悬浮在树上某个节点 → 页面对应元素高亮
- 点页面别处 → 换目标；再点已选中的元素 → 取消选中
- `Esc` → 退出选择模式

## 隐私

**不联网、不上传、不统计。**

- 扩展本身不发起任何网络请求，没有后端、没有账号
- 规则只存在你自己浏览器的 `chrome.storage.local`，卸载即清空
- 权限只有三个：`storage`（存规则）、`scripting`（页面脚本缺失时补注入）、`sidePanel`（侧边栏），
  加 `<all_urls>` 是为了在任何网站都能工作

| 浏览器 | 状态 |
|---|---|
| Chrome 114+ | ✅ |
| Edge 114+ | ✅ |
| Brave / 360 / 夸克等 Chromium 内核 | ✅（内核需 ≥114） |
| Firefox | ⏳ 需要单独适配（侧边栏是 Chromium 独有接口） |
| Safari | ⏳ 未适配 |

## 从源码构建（开发者）

```bash
pnpm install
pnpm build            # 产物在 .output/chrome-mv3
pnpm zip              # 打包成可上传的 zip
```

### 自测

```bash
node scripts/server.cjs &          # 本地测试页 :8941
node scripts/verify-real.cjs       # 端到端（生产路径）
node scripts/verify.cjs            # 完整套件
```

测试全部用无头 Chrome + CDP，不会弹窗口。
